# Studio & Publisher / 預渲染預覽 + No.16 FFmpeg 影片合成

## 文件資訊

- 版本：v1.0
- 範圍：`Studio & Publisher`、`預渲染預覽`、`No.16 FFmpeg 影片合成`

## 背景

目前使用者已可在 `Studio & Publisher` 中檢查字幕、分鏡、單字卡與單張 AI 圖，但在正式產出影片前，仍缺少一個整集級的最終預覽與直接執行 `No.16 FFmpeg 影片合成` 的工作區。使用者希望在同一頁完成整集檢查、啟動合成、追蹤 log、確認輸出結果，避免在 `Pipeline Manager` 與 `Studio & Publisher` 之間來回切換。

## 目標

1. 在 `預渲染預覽` 中提供整集級預覽，而非單一 scene 預覽。
2. 使用者可直接在 `預渲染預覽` 中啟動 `No.16 FFmpeg 影片合成`。
3. 合成執行中可即時看到狀態與 log，按鈕需 disabled。
4. 合成完成後可立即看到輸出影片與結果狀態。

## 非目標

1. 不在此版本新增影片時間軸逐幀剪輯功能。
2. 不在此版本支援拖拉調整 scene 時長。
3. 不在此版本取代 `Pipeline Manager` 的完整 stage 控制。

## 目標使用者

1. 內容製作人員
2. 字幕校對人員
3. 影片上架前的最終審核人員

## 核心使用情境

1. 使用者完成字幕與分鏡調整後，進入 `預渲染預覽`，播放整集音訊並同步檢查圖片與字幕。
2. 確認無誤後，直接按下 `執行 No.16 FFmpeg 影片合成`。
3. 在同一頁查看執行中的 log、進度狀態與輸出檔案。
4. 若失敗，根據 log 回頭修正字幕、圖片或分鏡後再次執行。

## 功能需求

### A. 整集預覽

1. 顯示整集音訊播放器。
2. 播放時依 `storyboard.csv` 自動切換目前 scene 圖片。
3. 播放時依 `.srt` 時間軸自動切換目前字幕。
4. 顯示當前 scene 的基本資訊：
   - `scene_id`
   - `start_time / end_time`
   - `source_type`
   - `flashcard_word` 或圖片路徑
   - `reason`
   - `image_prompt`
5. 提供 Scene 時間軸清單，可點擊跳轉。
6. 提供字幕時間軸清單，可點擊跳轉。

### B. No.16 執行控制

1. 在 `預渲染預覽` 區塊內新增 `執行 No.16 FFmpeg 影片合成` 按鈕。
2. 執行前需檢查必要輸入是否齊備：
   - 合成音訊存在
   - 分鏡表存在
   - 必要圖片可解析
   - 字幕存在
3. 若條件不足，按鈕 disabled，並顯示缺少項目。
4. 按下後以背景程序執行，不阻塞整頁操作。
5. 執行中按鈕 disabled，文案改為 `執行中...`。
6. 若已有同一集的 No.16 正在執行，不可重複啟動。

### C. Log 與狀態

1. 顯示 No.16 的目前狀態：
   - `未執行`
   - `執行中`
   - `成功`
   - `失敗`
2. 顯示 PID 或對應背景 task 資訊。
3. 顯示即時 log 面板。
4. log 在執行中需自動刷新。
5. 提供 `只刷新 No.16 狀態 / Log` 按鈕，不刷新整頁、不跳離目前頁籤。

### D. 輸出結果

1. 合成成功後顯示輸出影片路徑。
2. 若輸出影片存在，直接提供播放器預覽。
3. 顯示輸出檔大小、最後修改時間。
4. 若失敗，保留最後一段錯誤 log 供診斷。

### E. 與既有流程整合

1. `預渲染預覽` 應與 `No.13 分鏡編輯`、字幕編輯結果保持一致。
2. 若使用者重產單張 AI 圖或修改字幕後，重新進入本頁應讀到最新資料。
3. `Pipeline Manager` 的 No.16 狀態應與此頁一致。

## UI / UX 要求

1. 頁面分成兩大區：
   - 上半部：整集預覽播放器
   - 下半部：No.16 執行控制與 log
2. `執行 No.16` 按鈕需明確獨立，不與 Metadata / Upload 混淆。
3. 執行中需有明確視覺狀態，避免使用者重複點擊。
4. 預覽與 log 刷新不能把使用者導回 `Dashboard`。

## 成功指標

1. 使用者可在單一頁面完成整集檢查與影片合成。
2. No.16 執行中的重複點擊率下降。
3. 因切頁或看不到 log 而造成的操作中斷明顯減少。
4. 上架前能更快發現字幕、圖片、scene 對位問題。

## 驗收標準

1. 進入 `預渲染預覽` 時，可播放整集音訊並同步看到圖片與字幕切換。
2. 點擊 Scene 或字幕時間軸，可正確跳轉到對應時間。
3. `執行 No.16 FFmpeg 影片合成` 可在本頁成功啟動背景任務。
4. 任務執行中，按鈕 disabled，log 自動更新。
5. 點擊 `只刷新 No.16 狀態 / Log` 不會離開當前頁面。
6. 合成完成後可在本頁直接播放輸出影片。
7. 合成失敗時可在本頁看到足夠診斷的錯誤 log。

## 後續可延伸項目

1. 顯示 FFmpeg 進度百分比或估計剩餘時間。
2. 支援合成前的輸出解析度或字幕樣式選項。
3. 支援 `No.15` 與 `No.16` 串接的一鍵重跑。
4. 支援影片輸出版本管理與多次產出比較。
